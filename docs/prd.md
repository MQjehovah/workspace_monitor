# 产品需求文档：重大项目全景监控看板（V1.0）

## 1. 产品概述

* **产品定位** ：面向公司管理层、PMO及项目总监，提供重大项目进度、目标达成、考核结果的实时监控与智能分析工具。
* **核心价值** ：
* **直观** ：一屏掌握所有重大项目的健康状态。
* **穿透** ：从宏观KPI到明细项目，支持下钻分析。
* **洞察** ：内置风险预警、归因分析、趋势预测，辅助决策。
* **目标用户** ：高管（看趋势/风险）、PMO（管进度/考核）、项目经理（看自身排名/改进点）。

## 2. 业务数据模型

每个项目应包含以下核心字段（示例）：

* 项目ID、名称、负责人、所属部门、计划周期。
* **进度指标** ：计划完成百分比（基于关键里程碑实际/计划）。
* **目标达成指标** ：核心OKR/KPI达成率（例如营收贡献、上线功能数等）。
* **考核指标** ：综合考核得分（可包含进度得分、质量得分、成本得分、协作得分等）。
* **其他** ：风险等级、最近更新日期、预警阈值。

## 3. 功能模块与页面布局

### 3.1 全局KPI卡片区（第一屏）

* **展示内容** ：
* 重大项目总数
* 平均进度（%）
* 平均目标达成率（%）
* 平均考核得分（百分制）
* 风险项目数（进度<60% 或 达成率<70% 或 考核<70分）
* **交互** ：点击任意卡片可跳转到对应的筛选视图（如点击“风险项目数”展示风险项目列表）。

### 3.2 可视化分析区（核心图表）

#### 3.2.1 项目进度对比图（柱状图/条形图）

* **X轴** ：项目名称； **Y轴** ：进度百分比
* **辅助线** ：目标进度基准线（如计划当前应达进度）
* **颜色逻辑** ：进度<50%红色，50%-75%橙色，≥75%蓝色
* **交互** ：悬停显示具体数值、计划剩余天数；点击柱子下钻到该项目详情页。

#### 3.2.2 目标达成率分布图（柱状图+趋势线）

* 展示每个项目的目标达成率，并叠加整体平均线。
* 可切换为“部门达成率排行榜”。

#### 3.2.3 考核得分雷达图（或分组柱状图）

* 展示各项目考核总分及分项得分（进度、质量、成本、协作）。
* 便于横向对比短板。

#### 3.2.4 进度 vs 达成率散点图（高级分析）

* 横轴为进度，纵轴为达成率，气泡大小表示考核得分。
* **四象限** ：
* 第一象限（高进度+高达成）：优秀项目
* 第二象限（低进度+高达成）：目标激进，执行滞后
* 第三象限（低进度+低达成）：严重风险
* 第四象限（高进度+低达成）：过程虚假繁荣，质量或价值未达预期
* 提供象限解读和行动建议。

### 3.3 智能数据分析面板（右侧/底部）

* **自动生成文本洞察** ，包括：
* 风险预警：“XX项目进度仅45%，低于阈值，建议增加资源”
* 异常模式：“新能源项目达成率与进度偏离超过30%，需重新评估目标”
* 最佳实践：“AI中台项目进度92%，考核94分，可作为标杆”
* 整体趋势：“本月平均进度环比提升5%，但达成率下降2%，注意目标调整”
* **支持按时间维度（周/月）展示趋势对比** 。

### 3.4 重大项目明细表格（可搜索、排序）

* 列字段：项目名称、进度（含进度条）、目标达成率（含进度条）、考核得分、考核等级（A/B/C/D）、健康状态（健康/需关注/高风险）、负责人、操作（详情）。
* **排序** ：默认按风险程度倒序（高风险置顶）。
* **筛选** ：按部门、考核等级、健康状态。

### 3.5 考核与改进追踪模块（第二期可迭代）

* 针对低分项目自动生成改进任务，关联到负责人。
* 历史考核得分趋势图，展示项目绩效变化。

## 4. 数据分析逻辑（重点）

### 4.1 健康度评分模型

* **综合健康度 = 进度得分×30% + 目标达成率得分×40% + 考核得分×30%**
* 进度得分 = 实际进度/计划进度（若>1则取1）
* 达成率得分 = 实际达成/目标值（上限1）
* 最终健康度分为：健康(≥85)、需关注(70~85)、高风险(<70)

### 4.2 预警规则（自动触发分析）

| 预警类型        | 触发条件                           | 推送对象     |
| --------------- | ---------------------------------- | ------------ |
| 进度严重滞后    | 进度 < 60% 且 距离计划完成<30%时间 | 项目总监+PMO |
| 目标持续不达标  | 连续两次考核达成率 < 70%           | 部门负责人   |
| 考核分断崖下跌  | 考核分环比下降 >15分               | 项目负责人   |
| 高风险项目超3个 | 健康度为“高风险”的项目数 >3      | 高层管理者   |

### 4.3 归因分析（自然语言生成）

* **关联规则挖掘** ：例如“项目进度延迟是否导致目标达成率下降？”利用历史数据输出相关性（如相关系数>0.7）。
* **聚类** ：将项目分为“快速交付型”“质量优先型”“风险徘徊型”，并给出不同管理策略。

## 5. 交互与体验要求

* **响应式布局** ：支持PC端大屏（首选）及平板查看。
* **实时/准实时** ：数据每日凌晨同步，看板支持手动刷新。
* **下钻路径** ：点击图表中的项目 → 弹出侧边抽屉，展示该项目详细进度、里程碑、考核分项及改进建议。
* **导出功能** ：支持导出当前视图为PDF/Excel，用于会议汇报。

## 6. 非功能性需求

* **权限控制** ：高管可见所有项目；PMO可见所辖部门；项目经理仅见自己项目。
* **性能** ：图表加载<2秒，支持最多200个项目同时展示。
* **数据安全** ：敏感考核数据脱敏处理（如姓名、具体金额）。

## 7. 关键成功指标（验收标准）

* 用户能够**30秒内**识别出所有风险项目及其原因。
* 智能分析洞察准确率≥90%（与人工复盘结论一致）。
* 项目进度监控覆盖率100%，考核数据自动化率达到80%以上。

## 8. 迭代路线图

* **V1.0（MVP）** ：上述核心图表+明细表+基础预警。
* **V1.1** ：增加考核改进任务闭环、历史趋势对比。
* **V2.0** ：引入AI预测（预测未来进度偏差、考核分），集成钉钉/飞书机器人主动推送。
